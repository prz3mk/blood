# Blood

Idle vampire browser game (PWA).

- `npm run dev` – dev server
- `npm test` – Vitest
- `npm run balance` – bot simulation: time to first prestige (active / casual / idle)
- `npm run build` – typecheck + build

Modules: `src/engine` (state, tick, formulas) · `src/data` (definitions) · `src/save` · `src/ui` (Vue).
